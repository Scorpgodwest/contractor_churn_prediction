# Contractor Churn Prediction - SberBank AI Challenge

## Описание проекта

### Задача
В строительной отрасли управление подрядчиками и предотвращение дебиторской задолженности являются критически важными задачами. Проблемные подрядчики могут нарушить сроки выполнения проектов, что приведёт к значительным финансовым потерям и задержкам. Компании, такие как Самолёт, накопили большие массивы данных по взаимодействию с подрядчиками, их качеству и скорости выполнения работ, что позволяет выявить ключевые зависимости для своевременного предотвращения рисков.

В данном проекте мы решаем задачу прогнозирования "дефолта" подрядчика. Под "дефолтом" понимается снижение объёма работ по договору более чем на 10%, что зафиксировано в Акте разграничения объёмов работ (АРОР) или Акте сверки объёмов работ (АСОР). Основная цель — построить модель, которая предскажет вероятность дефолта подрядчиков на горизонте 6 месяцев.

### Данные
Для решения задачи предоставлены исторические данные о взаимодействиях с подрядчиками:
1. **train_X.csv** — файл с историческими данными по договорам, включающий различные характеристики, связанные с подрядчиками и их деятельностью.
2. **train_y.csv** — файл с метками классов, где указано, произошёл ли дефолт для конкретного договора.
3. **test1_X.csv** — файл с тестовой выборкой данных, на основе которой необходимо сделать предсказания.
4. **описание.xlsx** — файл с подробным описанием колонок в данных.

Данные нормализованы и представлены на еженедельной основе, что позволяет анализировать динамику выполнения работ и своевременно реагировать на изменения.

### Цель
Необходимо разработать модель, которая по каждому договору будет предсказывать вероятность "дефолта" подрядчика в диапазоне от 0 до 1 на горизонте 6 месяцев. Модель должна быть способна эффективно работать с нормализованными временными рядами и учитывать различные факторы риска для подрядчиков.

### Метрика
Для оценки эффективности модели используется коэффициент Джини, основанный на метрике AUC-ROC:
```text
Gini = 2 * AUC-ROC - 1
Подход к решению

Мы применяем метод стэкинга на основе ансамбля моделей и используем бустинговые методы для построения точных прогнозов вероятности дефолта. Для оптимизации параметров используется Hill Climbing.

Основные модели:
Random Forest
Extra Trees
HistGradientBoosting
LightGBM
XGBoost
CatBoost
Валидация
Для корректной оценки качества модели и предотвращения переобучения используется метод стратифицированной k-fold кросс-валидации с учётом группировок по подрядчикам. Это позволяет учесть специфику данных, связанных с разными договорами и проектами.
